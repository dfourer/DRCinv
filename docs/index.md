# DRCinv Documentation

DRCinv is a Python library for forward dynamic range compression,
expansion, and model-based inversion of audio signals.

The library provides two main functions:

- `drc_forward`: apply compression or expansion.
- `drc_inverse`: reconstruct the original signal from processed audio.

## Installation

```bash
pip install drclibrary
```
